Fusion au format PDF (v1.1 – 03/11/2026)

⚙️ Principe & Fonctionnement :
   •  Action : Glissez-déposez, ordonnez et validez.
   •  Sécurité : Les fichiers d'origine ne sont jamais modifiés (photos 360° d'origine rangées dans \360\ ; les nouveaux PDF sont créés dans le même dossier).
   •  Langue : Paramètres > Langue (français, anglais, allemand, espagnol). Elle est demandée au premier lancement et après chaque mise à jour.

📂 Formats pris en charge :
   •  PDF
   •  Images : JPEG, PNG, GIF, TIFF, BMP, HEIC/HEIF
   •  Microsoft Office : Word, Excel, PowerPoint (nécessite les logiciels installés)

🔄 Les Trois Modes
   •  1. Fusion
        Action principale : Regroupe tous les fichiers de la liste dans l'ordre.
        Résultat : Un seul PDF combiné (<nom>_fusion_01.pdf)
   •  2. Conversion
        Action principale : Transforme chaque fichier individuellement en PDF.
        Résultat : Un PDF par fichier d'origine
   •  3. Scission
        Action principale : Découpe un PDF multipage page par page.
        Résultat : Un PDF par page (<nom>_page_01.pdf)

Option « Compresser les pdf »
   •  Case à droite au-dessus de la liste : les PDF produits (fusion, conversion, scission) sont allégés : images réduites et recompressées en JPEG, texte et dessins inchangés.
   •  Taux de compression : curseur sous la case, de « Léger » (meilleure qualité) à « Fort » (fichier le plus léger).
   •  Liste de PDF uniquement : le mode Compression crée une copie compressée de chaque PDF (<nom>_compresse.pdf).

Option « Mosaïque »
   •  Visible si la liste ne contient que des images : crée un seul PDF (<nom>_fusion_01.pdf).
   •  Premières pages : planches A4 paysage de 10 photos maximum, avec le nom de chaque photo.
   •  Pages suivantes : chaque photo en grand, une par page.
   •  Navigation : un clic sur une vignette affiche la photo en grand ; un clic sur la photo en grand revient à la planche.

Photos 360° (Samsung Gear 360)
   •  Détection automatique : une photo brute à deux cercles (double fisheye) est reconnue.
   •  Mise à plat : elle est dépliée en panorama 360° (format 2:1) dans le PDF ; la photo d'origine est ensuite déplacée dans le sous-dossier \360\ du PDF.
   •  Immersion : le bouton « Voir en 360° (immersion) » sous chaque panorama ouvre la visionneuse 360° de FusionPDF (fichier 360\<nom>_360.pano360). Il n'est pas imprimé. Le panorama <nom>_360.jpg est enregistré à côté du PDF. Réglage : Paramètres > Visionneuse 360° > Afficher le bouton visionneuse sur le PDF.

Pages et aperçu
   •  Exclure des pages : clic droit sur un PDF de la liste > Afficher les pages (ou double-clic). Cliquer sur la case ☑ / ☐ d'une page (ou Espace) l'exclut de la fusion et de la scission.
   •  Aperçu : case Aperçu au-dessus de la liste : la page ou l'image sélectionnée s'affiche à droite (flèches pour changer de page, case « Page incluse »).
